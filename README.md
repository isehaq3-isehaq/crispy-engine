# شاي سيّار — إعادة تنظيم وحدة المخزون والصرف

إعادة تنظيم صفحات المخزون في نظام `sayyar.adwa-kamma.com` بأسلوب أنظمة المقاهي الاحترافية
(مخزن رئيسي ← أذونات صرف للبار/المطبخ ← هالك واستهلاك ← جرد فعلي وتسوية ← كرت الصنف).

## الملفات
| الملف | الحالة | الوصف |
|---|---|---|
| `sayyar/inventory_lib.php` | جديد | تعريف المخازن، أنواع الحركات، جدول `inventory_movements` ودوال التسجيل وترقيم السندات |
| `sayyar/stock_issue.php` | جديد | صفحة **صرف وحركة المخزون** بأربع مراحل: إذن صرف/تحويل، صرف استهلاك وهالك، الجرد الفعلي والتسوية، سجل الحركات وكرت الصنف |
| `sayyar/main_inventory.php` | معدّل | لوحة **أرصدة المخازن**: إجراءات سريعة، مؤشرات (القيمة، المنخفض، النافد، هالك اليوم)، بطاقات المخازن، فلتر «يحتاج إعادة طلب»، النماذج في نوافذ منبثقة، وتوثيق أي تعديل يدوي للكمية |
| `sayyar/sidebar.php` | معدّل | قسم المخزون مرتب حسب سير العمل + تمييز الصفحة الحالية |
| `original/` | — | نسخ الملفات الأصلية من السيرفر قبل التعديل (للمقارنة والاسترجاع) |

## ملاحظات تقنية
- جدول جديد `inventory_movements` يُنشأ تلقائياً (`CREATE TABLE IF NOT EXISTS`)، ولا تُحذف أو تُعدّل أي بيانات قائمة.
- جميع العمليات داخل Transactions مع `FOR UPDATE`، وحماية CSRF، والتحقق من انتماء الصنف للفرع، ومنع الصرف بأكثر من الرصيد.
- التحويل بين المخازن ينقل التكلفة بالمتوسط المرجّح وينشئ الصنف في المخزن المستلم إن لم يكن موجوداً.
- أسماء حقول النماذج القديمة في `main_inventory.php` لم تتغير.
